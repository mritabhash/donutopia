# Donutopia

Each round of Donutopia gives you seven open-ended questions. The challenge is to think of an answer that fits the prompt but few other players would think to give. A Cloudflare Worker checks each answer and estimates its rarity.

Reev’s built includes the question bank, answer judging, collectible Baking Buddies and bakery rewards. The repository also includes a private-room service for playing with friends.
