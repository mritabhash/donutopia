# Donutopia

A bakery-themed browser game by Ritabhash Mondal. Each round gives you seven open-ended questions. The challenge is to think of an answer that fits the prompt but few other players would think to give. A Cloudflare Worker checks each answer and estimates its rarity.

Donutopia’s project-specific work includes the question bank, answer judging, collectible Baking Buddies and bakery rewards. The repository also includes a private-room service for playing with friends. The current frontend incorporates previously captured game pages and assets.
